# 打字練習（中打／英打）

給國小學生的鍵盤指法練習工具。參考「校園打字 GAME」（tgame.eduweb.com.tw）的課程骨架，
但題庫、程式與判分方式都是自己寫的。

## 關卡編排

中英兩套對稱，都是「從基準列出發，一次只加一列」：

| 關 | 英打 | 中打（第②批） |
| --- | --- | --- |
| 1 | 基準列 ASDF JKL; | 基準 ㄇ 列 |
| 2 | 基準列 + 下排 ZXCV | ㄇ + ㄈ 列 |
| 3 | 基準列 + 上排 QWER | ㄇ + ㄆ 列 |
| 4 | 三列混合 | ㄇ + ㄅ 列（數字列） |
| 5 | 數字列 | ㄇ+ㄆ+ㄈ 混合 |
| 6 | 全部按鍵（含 Shift 大寫） | 全部注音 + 聲調 |

每一關的題目分兩段：前段 `drills` 練鍵位、後段 `words` 是只用該關教過的字母
組成的真單字，讓孩子知道學這些鍵可以拼出什麼。

## 過關方式：星等，不是及格線

打完就有 1 顆星，正確率 ≥ 90% 給 2 顆，又準又快給 3 顆。

指法練習的重點是把手指位置練到不用想，不是逼低年級追速度。用及格線的話，
慢的孩子會卡在同一關過不去；用星等，每個人都走得完，想追求的人有得追。

速度標準（第 3 顆星）定在各關 8～14 WPM，定義在 `js/engine.js` 的 `WPM_TARGET`。

## 三個「電腦教室現場」守門

這三種狀況都是**不會報錯、畫面也沒反應**的，孩子只會覺得電腦壞了：

| 狀況 | 程式怎麼處理 |
| --- | --- |
| 輸入法停在注音 | `keydown` 收到的鍵名是 `Process` / `Unidentified`，跳提示教他按 Shift 切換 |
| Caps Lock 亮著 | 按對鍵卻打出相反大小寫時，跳提示叫他關掉 |
| 瀏覽器擋網站資料 | `localStorage` 存取失敗不會中斷遊戲，只是這次成績不會被記住 |

## 視覺：可愛，但不能蓋掉教學功能

畫面是一片天空，卡片是浮在上面的雲，按鍵是圓潤的糖果鍵帽。

吉祥物「小鍵」**本身就是一顆鍵帽**——這個工具從頭到尾在講鍵盤，
吉祥物不該是隨便貼上去的動物。它有四種表情（平常／開心／嚇一跳／星星眼），
打對打錯會跟著反應，台詞同一情境內隨機挑，免得整堂課聽到同一句。

裝飾可以加，但這兩件事是教學功能不是美術，不能被蓋掉：

1. **手指配色**（鍵帽頂端那條色帶）——孩子靠顏色認「這顆鍵歸哪根手指」
2. **目標鍵的打光**——畫面上最亮的東西必須是「現在要按的那顆」

彩帶和小星星都是純 CSS 做的，沒有為了這個去載 confetti 套件。

## ⚠️ 改 CSS 前先看這個

這個專案踩過**兩次**同一種特異性陷阱，兩次都是「顏色安靜地失效、沒有任何錯誤訊息」：

| 位置 | 錯誤寫法 | 後果 |
| --- | --- | --- |
| 鍵帽手指色帶 | `.kb-key[class*="finger-"] { border-top: 3px solid transparent }` | (0,2,0) 壓過 `.finger-L5` (0,1,0)，整組手指配色變透明 |
| 吉祥物眼睛高光 | `.m-glint { fill: #fff }` | (0,1,0) 被 `.m-eyes circle` (0,1,1) 壓成深色，眼睛死掉 |

規則：**形狀（寬度、有無）寫在基底類別，顏色寫在修飾類別**，
而且修飾類別的特異性不能比基底低。兩處都已在原地留了註解。

## 兩個會自己吵的資料檢查

改題庫或鍵位表時，這兩個檢查會在載入時跑，出問題直接在畫面上跳提示：

- `keymap.js` — 大千式的 37 個注音必須各佔一鍵，多、少、重複都會被抓出來。
  大千式是「直行」排的：`1/q/a/z` 直下來是 ㄅㄆㄇㄈ，`2/w/s/x` 是 ㄉㄊㄋㄌ，
  依此類推剛好填滿 37 個，這個性質就是最好的驗證。
- `levels-en.js` — 每一關的題目不能用到該關還沒教的鍵。

## 為什麼不用 CDN

全部用系統內建字型、沒有任何外部框架，`index.html` 拷到隨身碟雙擊就能開。

2026-08-25 教網中心對外斷線那次，學校主機對外 80／443 全不通。
課如果排下去、工具又掛在 CDN 上，就是一整堂空白。
