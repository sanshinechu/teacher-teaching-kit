# 電腦課神隊友（羅東國小專屬版）

## 目的

專為國小資訊科任老師與資訊組長設計的「電腦教室課堂管理儀表板」。整合 **29 台主機座位視覺化排位、跨班學生搜尋、課堂隨機抽籤、當堂作業完成／加分／請假標記、各班教學進度交接與歷程紀錄、20 項科技能力樹追蹤，以及跨班連動的機台設備報修專區**。

## 使用對象

- 年級：三～六年級資訊課、科技社團
- 科目：資訊科技（Scratch 動畫、Scratch 遊戲、AI 模組應用、數位素養等）
- 使用者：電腦科任教師／資訊組長

## 專案類型

- 靜態網頁工具（支援本機 `LocalStorage` 自動儲存 + JSON 備份匯出入 + Google Apps Script 試算表雲端自動同步）

## 教室座位配置（電腦老師前視圖，共 29 台主機）

- **講台與投影大螢幕**：位於畫面正下方（可一鍵 180° 翻轉為「學生面向講台投影視角」）。
- **第 1 排（最靠講台）**：由左至右顯示 `PC-08` ～ `PC-01`（即由右至左為 `1～8` 號）
- **第 2 排**：由左至右顯示 `PC-16` ～ `PC-09`（即由右至左為 `9～16` 號）
- **第 3 排**：由左至右顯示 `PC-24` ～ `PC-17`（即由右至左為 `17～24` 號）
- **第 4 排（最後一排）**：由左至右顯示 `空位、空位、PC-28、PC-27、PC-26、PC-25、PC-29、空位`

## 結構

```text
電腦課神隊友/
├─ README.md
├─ index.html       # 主畫面與互動彈窗（名單匯入、年級進度對照、抽籤動畫、雲端設定）
├─ styles.css       # 單頁高密度儀表板樣式與投影翻轉模式
├─ script.js        # 座位排布、跨班搜尋、進度歷程、機台報修連動與雙模式存檔邏輯
└─ gas/
   └─ Code.gs       # Google 試算表自動同步後端腳本（選配）
```

## 使用方式

1. 直接以瀏覽器開啟 `index.html` 即可使用（所有修改會自動儲存於瀏覽器 `LocalStorage`）。
2. 點擊頂部 **「👥 班級與名單管理」** 可新增／修改班級、上課節次，或直接貼上全班學生姓名清單自動入座 `PC-01`～`PC-29`。
3. 如需跨電腦（例如在資訊組主機與電腦教室講台機之間）自動同步：
   - 建立一份空白 Google 試算表，點選「擴充功能 > Apps Script」。
   - 將 `gas/Code.gs` 內容貼上，部署為「網頁應用程式（所有人可存取）」。
   - 將取得的網址貼入本工具右上角 **「☁️ 備份/同步」** 設定中，即可即時雙向同步。
