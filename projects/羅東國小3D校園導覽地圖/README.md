# 羅東國小 3D 校園導覽地圖

> 本專案參考「明新科技大學 3D 校園導覽地圖」（純前端 Three.js 參數化建模 + 輕量化無外部大型 3D 模型架構），為宜蘭縣羅東國小量身打造的互動式 3D 校園導覽系統。

## 專案位置
- **路徑**：`04_教師用教學套件/projects/羅東國小3D校園導覽地圖/`
- **所屬套件**：[teacher-teaching-kit](https://github.com/sanshinechu/teacher-teaching-kit.git)

## 核心設計理念與架構
1. **零外部大模型負擔**：不依賴巨大的 `.gltf` / `.fbx` 3D 模型檔，採用 Three.js 幾何積木（盒子、圓柱、自訂多邊形擠出）參數化繪製教學大樓、操場與景觀，極速載入、手機順暢。
2. **三種導覽視角**：
   - 3D 鳥瞰視角（Orbit）
   - 2D 俯視地圖（Top）
   - 第一人稱漫遊（Walk，含 WASD / 虛擬方向鍵控制與校舍碰撞偵測）
3. **豐富資訊互動**：
   - 校舍地點點選飛入鏡頭
   - 處室與專科教室（例如電腦教室、校史室、圖書館）分佈介紹
   - 精選校園導覽路徑自動巡航
   - 即時動態指北針與日夜風格切換
4. **客製化外觀與字體**：
   - 霞鶩文楷 TC（LXGW WenKai TC）優雅手寫風格
   - Lucide Icons 清晰 UI 圖示

## 目錄結構
```text
羅東國小3D校園導覽地圖/
├── index.html           # 導覽地圖首頁與 UI 面板
├── data/
│   ├── buildings.js     # 校舍、地標、操場座標與尺寸資料
│   └── offices.js       # 各處室、班級教室與專科教室樓層配置
├── src/
│   ├── scene.js         # Three.js 3D 場景、燈光、日夜與攝影機控制
│   ├── builder.js       # 參數化校舍、跑道、球場與植栽生成器
│   ├── controls.js      # 鳥瞰與漫遊視角切換、碰撞檢測
│   └── app.js           # 介面事件綁定、搜尋、導覽與彈窗邏輯
└── assets/              # 相關地圖參考圖、學校校徽等靜態資源
```
