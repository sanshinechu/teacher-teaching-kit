# 羅小高年級科技課學習狀態（羅東國小；原名：電腦課神隊友）

## 目的

專為國小資訊科任老師與資訊組長設計的「電腦教室課堂管理儀表板」。整合 **29 台主機座位視覺化排位、跨班學生搜尋、課堂隨機抽籤、當堂作業完成／加分／請假標記、各班教學進度交接與歷程紀錄、20 項科技能力樹追蹤，以及跨班連動的機台設備報修專區**。

## 使用對象

- 年級：三～六年級資訊課、科技社團
- 科目：資訊科技（Scratch 動畫、Scratch 遊戲、AI 模組應用、數位素養等）
- 使用者：電腦科任教師／資訊組長

## 專案類型

- 靜態網頁工具（支援本機 `LocalStorage` 自動儲存 + JSON 備份匯出入 + Google Apps Script 試算表雲端自動同步）

## 教室座位配置（電腦老師前視圖，共 29 台主機）

- **講台與投影大螢幕**：位於畫面正下方（可一鍵 180° 翻轉為「學生面向講台投影視角」）。
- **第 1 排（最靠講台）**：由左至右顯示 `PC-08` ～ `PC-01`（即由右至左為 `1～8` 號）
- **第 2 排**：由左至右顯示 `PC-16` ～ `PC-09`（即由右至左為 `9～16` 號）
- **第 3 排**：由左至右顯示 `PC-24` ～ `PC-17`（即由右至左為 `17～24` 號）
- **第 4 排（最後一排）**：由左至右顯示 `空位、空位、PC-28、PC-27、PC-26、PC-25、PC-29、空位`

## 使用方式

1. 直接以瀏覽器開啟 `index.html` 即可使用（所有修改會自動儲存於瀏覽器 `LocalStorage`）。
2. 點擊頂部 **「👥 班級名單」**：
   - **單班**：貼上「座號、姓名」，照座號坐（5 號坐 PC-05）。缺號不用補空行、標題列自動略過；座號重複或超過 29 的從 PC-29 往回補空位。全部沒座號時照行的順序坐。
   - **全年級大量匯入**：貼上或選檔（.xlsx／.xls／.csv，Big5 也可）「班級、座號、姓名」。名單裡有的班整班換掉（節次、進度、星星保留），沒有的班不動，新班先設星期一第 1 節。工作表名稱是班級（如「6年1班」）時，該表只要座號、姓名兩欄。
   - **清空本班名單**、**勾選批次刪除班級**（至少留一班）。
3. 如需跨電腦（例如在資訊組主機與電腦教室講台機之間）自動同步：
   - 用**學校帳號**建立一份空白 Google 試算表（資料含學生姓名），點選「擴充功能 > Apps Script」。
   - 將 `gas/Code.gs` 內容貼上，**把 `SYNC_KEY` 改成自己的通關密碼（至少 8 碼，英文數字混用）**。存資料的試算表不用自己建：第一次開網址時自動建「羅小高年級科技課學習狀態_同步資料」，ID 記在專案的指令碼屬性（`SPREADSHEET_ID` 常數留空即可；要指定既有試算表才填）。獨立 Apps Script 專案的 `getActiveSpreadsheet()` 是 null，2026-11-10 實際部署測出，部署為「網頁應用程式」（執行身分：我；存取：所有人）。沒改密碼的話後端拒絕所有請求。
   - 要用「📚 Classroom」點選進度：部署前在 Apps Script 左側「服務」加入 **Google Classroom API**，授權時會多問 Classroom 讀取權限。課程 ID 在 `CLASSROOM_COURSES`，來源是 `12_備課工作流/Classroom/五六年級上架/Code.gs` 的 `COURSE_ID_MAP`，換學年要一起改。
   - 用瀏覽器直接開部署網址，看到「部署成功」字樣就對了。
   - 在工具的 **「☁️ 同步/備份」** 貼上網址與通關密碼，按「連線並同步」。
     - 第一台：雲端是空的，會問要不要把這台的資料傳上去。
     - 之後的電腦：**先下載雲端資料**，不會把雲端蓋掉。
   - 之後每次修改約 1.5 秒後自動上傳；開頁與切回分頁時自動抓別台的更新。兩台都改過時會跳出來問要留哪一份（後端用版本號擋，不會互蓋）。
   - 修改 `Code.gs` 後要「部署 > 管理部署作業 > 編輯 > 版本：新版本」才生效，網址不變。

### 作業繳交連結（依座號顯示）

座位圖上方的 **「📥 作業連結」** 可以把學生交的作品網址匯進來，顯示在各班各座號的座位格。

- **來源**：貼上文字，或選 Padlet 匯出的檔案（.csv／.xlsx）。每一列只需要「班級座號」和「網址」，不需要姓名。
  班級座號寫 `50509`、`505 9`、`505,09` 都可以（505 班 9 號）；只寫座號和網址的話算在目前這一班。
  程式不看欄位名稱，自己找出這兩格，所以 Padlet 匯出格式變了也認得。座號 `00`（老師示範）會略過。
- **同學陸續補交**：用**同一個作業名稱**再匯入一次。這次有的座號更新連結，其他人的保留，**不會變成第二份作業**
  （名稱比對忽略空白與全半形；作業名稱欄點一下可以直接選已有的）。預覽會先說是「補交更新」還是「新建一份」。
- **座位格**：有交作業的座號，名字左邊的頭像會換成藍色 🔗。只交一份點了直接開；交了多份會有數字，點了跳清單選。
- **看誰還沒交**：上方下拉選一份作業，已交的座位亮藍框、沒交的變淡，統計列多一項「🔗 已交 x/y」。
- **預覽會提醒**：名單上沒有的座號、同一個連結被兩個座號重複使用、工具裡沒有的班級。
- **資料存哪**：`cls.assignments = [{ id, title, links: { "09": 網址 } }]`，跟著瀏覽器資料與跨機同步走。
  以座號為鍵、不綁座位格，所以換座位、重新匯入名單都不會掉。只收 http／https 網址。
- 這個網站的原始碼是公開的，**學生作品連結不要寫進程式碼或 repo**，一律從畫面匯入。

### 同步的設計（改之前先看）

- 版本號：`系統狀態庫_請勿手動改` 工作表 C2，每次寫入 +1。網頁上傳附 `baseVersion`，跟雲端不同就回 `conflict`。
- 資料分段：試算表一格上限 5 萬字，JSON 每 4 萬字一段存在 A2 往下，D2 是段數。每段開頭加 `~`，避免片段以 `=`／`+`／`-` 開頭被當成公式。
- 通關密碼走 POST 內文，不放網址。`doGet` 只回「部署成功」，不回資料。
- 2026-11-10 測出並修掉：衝突時選「用這台覆蓋」，強制上傳會被「上傳中」旗標擋下改排一般上傳，又撞衝突 → 覆蓋永遠不會發生。現在衝突處理只回傳決定，強制上傳由上傳流程自己接。
